✅ Steps to Update & Deploy Portfolio

🔹 1. Make your changes in code
		(Edit your files in VS Code)

🔹 2. Run the following commands in terminal:
		git add .
		git commit -m "Adjust Height in choose Section"
		git push origin main
		npm run build
		npm run deploy
🔹 3. Build the updated project
		npm run build

🔹 4. Deploy to GitHub Pages (using gh branch)
		npm run deploy
